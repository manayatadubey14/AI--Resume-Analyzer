# 🤖 AI Resume Analyzer

A Python-based resume analysis tool that allows users to upload a PDF resume and compare it with a job description.

## 🎯 Objective

The goal of this project is to help students and job seekers understand how well their resume matches a particular job description and identify areas for improvement.

## ✨ Current Features

- Upload resume in PDF format
- Extract text from the resume
- Enter a job description
- Simple and user-friendly interface
- Built using Python and Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF2
- Scikit-learn

## 🔄 How It Works

1. Upload your resume in PDF format.
2. Enter the target job description.
3. The application extracts the resume text.
4. The resume is compared with the job requirements.
5. The application provides analysis and suggestions.
